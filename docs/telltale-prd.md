## 当前发布范围：1.0.0

2026年10月22日确定本次发布采用响应式 Web 应用，通过 GitHub 仓库导入部署至 Cloudflare Workers。当前版本以临时课程提供完整的故事学习流程；下文家庭账号、共享、语音服务、生成配图等需求保留为后续产品范围。

成人设置六位课堂口令，输入最多300个字符的中文经历或虚构故事，选择L/M/H难度并明确确认将文字发送至DeepSeek。使用deepseek-flash生成3–5句英语及中文、五张词卡、选择、配对和填空三类练习。自编故事以文字呈现；内置「公园的早晨」使用随应用提供的图片与音频。

服务端校验每句L≤8、M≤12、H≤16个词、词卡与例句引用、练习答案、填空还原和2–3个练习目标词。成人能够编辑生成文字、词卡及练习，保存后重新审核。原意、语言、难度、答案、儿童适宜性五项全部确认后方可进入儿童模式。模型指令与结构检查配合成人审核使用；独立内容安全服务、生成图片、ASR、TTS及家庭登录不属于本次发布。

儿童可以逐句阅读、查看词卡、完成三类练习、请求提示或成人帮助、休息并继续、跳过或提前结束。答案保留在服务端。作答按真实尝试、提示和帮助记录形成独立完成、支持下完成、重试完成及跳过证据，不提供诊断或注意力判断。休息保留当前页面选择；刷新需要成人重新验证并结束当前儿童运行。

结果页展示当课实际阅读、词卡与练习证据。成人验证后在浏览器生成并下载1080像素宽的PNG故事书。课程支持主动清理；连续15分钟无有效访问后失效，最长保留4小时。没有跨课个人档案。平台存储恢复历史与模型服务接收的数据处理范围在隐私说明中告知。

发布验收覆盖：真实DeepSeek生成，生成取消与失败处理，成人编辑与逐项审核，儿童访问隔离，服务端判题和重复请求幂等，三类练习、休息恢复、摘要、PNG下载、课堂清理、Workers持久化及生产域名访问。真实服务和浏览器检查结果分别保存于本地验收记录。

## 1 产品目标

TellTale English 为7–12岁、小学1–6年级的 ADHD 儿童提供英语故事学习。成人录入儿童愿意讲述的经历或虚构情节，系统生成分级英语、词卡、练习和配图，经过成人审核后开放学习。儿童逐句听读、完成练习，并在成人协助下保存本课绘本。家长可查看具体词语的练习证据，采用一条下次课程的陪伴建议。

产品支持任务启动、理解指令、等待、活动切换和中断恢复。儿童能够看懂当前任务、找到下一步操作，在休息后返回原位置。儿童可以拒绝分享真实经历、暂不跟读、跳过题目或结束本课，无需说明原因。

产品属于英语学习工具。产品功能不包含诊断、症状评估、治疗、用药建议、病情追踪、摄像头注意力识别和专注率计算。诊断证明、家庭背景、点击速度、休息次数与用时均不参与英语能力判定。

## 2 用户角色与使用场景

### 2.1 角色职责

| 角色 | 主要操作 | 访问范围 |
| --- | --- | --- |
| 儿童 | 选择故事、听读、查看词卡、作答、求助、休息、继续或结束 | 当前课程的已审核材料与本人本课反馈；无需独立注册 |
| 家长或监护人 | 登录、声明监护关系、授权、建立档案、准备课程、审核内容、保存作品和管理数据 | 本账号拥有的儿童档案、课程、记录和作品 |
| 机构老师或志愿者 | 创建临时课堂、准备和审核材料、协助儿童、查看当课小组摘要 | 当前课堂；进入成人设置须完成课堂成人验证 |
| 指定共享接收人 | 验证手机号后查看授权的记录或作品 | 共享所列对象、字段及有效期；无法修改儿童数据 |

### 2.2 使用场景

家庭课程建议10–15分钟，机构活动建议20–30分钟，单项任务建议1–3分钟。上述时长用于成人安排活动，不形成儿童倒计时，不决定课程成绩或奖励。

家庭通常由成人完成准备，再将同一设备交给儿童。平板与手机使用单栏或适当分栏，电脑成人审核页可同时查看材料与编辑区。进入儿童模式时锁定成人功能；返回家长记录或成人设置须验证成人身份。

机构使用共享设备开展当课活动。老师免注册创建课堂，系统建立临时课堂身份，集体作答和归属不明的结果只计入小组摘要。课堂结束时先提供摘要和保存作品的机会，成人结束课堂后清理当课数据。

## 4 产品参数与业务规则

### 4.1 内容和课程参数

| 参数 | 规定值或行为 | 依据 |
| --- | --- | --- |
| 年龄和年级 | 7–12岁，小学1–6年级；档案只选择年级段，不收集生日 | 两份方案的产品定位；最少采集原则 |
| 年级段 | 1–2年级、3–4年级、5–6年级 | 本文确定的界面选项 |
| 英语起点 | 刚开始接触、认识部分单词、能够理解简单句；由成人选择 | 项目方案书第2.3节；本文确定的选项 |
| 中文故事长度 | 建议20–150字；去除首尾空白后至少1个可见字符，最多300个 Unicode 码点；信息不足时要求成人补充 | 项目方案书第2.4节的建议长度和硬性上限 |
| 语音录入 | 成人操作，每段最多60秒、最多3 MB；转写后适用相同文字限制 | 项目方案书第2.4及4.4节 |
| 英语句子 | 每课3–5句；L、M、H每句分别最多8、12、16个英文词 | 两份方案 |
| 词卡 | 每课恰好5张，词语来自故事；含语境释义、故事例句和对应词义的图片 | 项目方案书第2.4节 |
| 重点练习词 | 成人从5个词中选择2–3个，复习词须在生成时进入故事 | 项目方案书第2.6及3.4节 |
| 练习 | 恰好3道：看中文选英文、单词配对、词库填空各1道；选择题3个选项，配对2–3组，填空词库2–3项 | 两份方案及本文确定的填空选项上限 |
| 绘本 | 当前审核版本的全部英语句子和对应配图，导出1张宽1080像素的 PNG，保留 AI 生成标识 | 两份方案 |
| 设置生效 | 开课后锁定难度和教学支持；中途修改写入下次课程 | 项目方案书第3.4节 |
| 延迟复习 | 距上次独立完成至少24小时，在另一课程的新题目中独立完成同一词语 | 本文确定的可验收时间和证据规则 |

词数计算、内容结构及判定算法由 Spec 规定，前后端使用同一实现。学习难度和教学支持分别设置，系统不因答错、反复点击或使用提示自动调整难度。

### 4.2 Web 会话与访问规则

休息恢复适用于同一浏览器标签页、同一次页面运行、有效课程会话内的中断。页面在后台仍保留运行状态时，可返回原句、原题、词卡和未提交选项。刷新、关闭标签页、浏览器终止页面或切换设备后，当前作答草稿结束；已经提交的家庭学习记录继续保留。页面明确提示这一保存范围。

机构课堂显式结束时立即关闭访问。浏览器关闭事件可能无法送达，服务端通过15分钟无活动租约和最长4小时课堂有效期回收遗留课堂；恢复时若凭证已失效，说明课堂已结束并交由成人创建新课。休息页不展示倒计时。本文为 Web 会话确定上述时间参数。

家庭长期记录未获授权时，只开放预置示例的当课学习，临时数据于结束后清理。作品分享、语音录入分别授权；个人下载绘本不要求作品分享授权。撤回学习记录授权时停止个人记录写入，关闭相关共享，并进入既有个人学习数据删除流程。

## 5 用户操作流程

### 5.1 P1 成人进入与课程设置

家庭成人通过手机验证码登录，阅读服务说明，声明监护关系并分别选择三项授权。获得学习记录授权后，创建或选择儿童档案，设置年级段、英语起点、L／M／H难度、中文解释、音量、减少动效和复习词。机构成人创建临时课堂并设置成人验证口令，完成当课设置。

成人确认后交给儿童。儿童首页展示“我的故事”和1个“示例故事”；选定后才可开始。选择“我的故事”进入成人录入；选择示例进入成人内容确认。当前课程未结束时，切换档案须先完成结束操作。

### 5.2 P2 故事录入 内容生成与成人审核

成人输入文字，或授权录音并编辑转写结果。发送页面显示将要提交的全文、处理服务和身份信息提醒，成人逐字确认后提交。系统生成并校验文字、词卡、练习和图片，自动安全检测通过后进入成人审核。

成人检查原意、语法、难度、词卡词义、唯一答案和图片。成人修改形成新版本，依赖材料重新校验并再次审核。所有图片就绪、检测通过、检查项确认后，成人批准内容，系统为批准的句子合成音频；全部媒体就绪后才开放儿童学习。

### 5.3 P3 等待 失败与取消

提交后1秒内显示真实处理阶段和取消入口。重复点击返回同一个任务。文字生成目标为45秒内完成，自动重试最多3次，全部尝试共享45秒文字处理期限。

达到期限或次数限制时显示具体原因，保留成人已确认文字，成人可重新发起、选择标注清楚的示例并确认，或结束。取消和结束立即阻止结果进入本课，迟到结果不得覆盖当前课程。

### 5.4 P4 逐句听读与词卡

每次呈现一句英语、对应中文和配图。儿童手动播放，播放按钮原位切换为停止；切换句子、打开休息、退出学习或页面进入后台时停止声音。同一时间只播放一段声音。

点击重点词可打开一张词卡，关闭后回到原句。五张词卡逐张浏览。最后一句的主按钮显示“进入小练习”，继续学习不要求录制跟读或完成口语评测。

### 5.5 P5 互动练习与反馈

每次显示一道练习和当前步骤。儿童确认前可修改选择或撤销配对，选择不完整时说明缺少内容。系统只在儿童提交后进行判定，分别记录首次作答、提示后作答和重做。

答对后说明完成的具体内容；答错后提供重听、提示、重试和跳过。反馈保持到儿童主动继续。配对逐组确认，全部配对完成或儿童跳过整题后才进入下一题。第3道结束后显示本课成果。

### 5.6 P6 帮助 休息与提前结束

帮助提供“再听一次”“看提示”“请大人帮忙”，保留已选内容。休息立即停止音频和动效，保存句子、题目、已选选项、配对进度和已展开词卡，显示“准备好后再继续”。

继续时回到原位置，用一句话回顾当前任务，音频保持停止。儿童可以随时结束本课，保留已提交成果，未完成部分明确显示，不扣除奖励，也不要求补做。

### 5.7 P7 作品 记录与数据管理

成人进入绘本预览，确认后生成并下载图片。生成成功与浏览器开始下载分别提示。家长验证身份后查看词语证据、课程详情和作品，采用一条下次建议。机构成人查看当课小组摘要，完成需要的图片下载后结束课堂，系统清理临时内容。

家长可共享选定记录或作品、导出数据、删除儿童档案和注销账号。每项操作展示范围、身份验证要求与真实处理状态。

## 6 功能需求与验收条件

### 6.1 账号 档案与课程准备

**PRD-001 家庭登录。** 支持手机号与短信验证码，提供验证码错误、过期、发送过于频繁、服务不可用及登录过期提示。退出登录后当前儿童访问能力同步失效。

验收：正确验证码建立会话；错误或过期验证码拒绝登录；达到发送限制后显示可再次发送的时间；错误不清空已填手机号；生产环境不接受固定验证码。

**PRD-002 分项授权。** 三项授权分别为学习记录、成人语音录入、作品分享，初始均未勾选。展示处理目的、范围、服务及撤回入口，保存监护关系声明和说明版本。

验收：拒绝语音仍可文字录入；拒绝分享仍可学习和下载本人作品；拒绝长期记录仅可示例当课学习；撤回后对应接口立即禁止新处理，已有数据依第10章清理。

**PRD-003 儿童档案。** 家长建立昵称、年级段、英语起点和预置头像，支持多个档案。无需真实姓名、照片、学校、住址、生日或诊断信息。

验收：只显示当前成人有权访问的档案；修改编号无法获取其他家庭的数据；进行中的课程结束后方可切换档案；无授权时不建立持久档案。

**PRD-004 临时课堂。** 机构成人免注册创建课堂，设置仅本课使用的成人验证口令。课堂中的儿童无需账号和个人身份资料。

验收：可完成机构准备与学习；进入成人设置须验证口令；其他课堂无法读取本课；课堂失效后旧入口和旧资源均拒绝访问。

**PRD-005 课程设置。** 设置年级段、难度、中文解释、音量、减少动效、2–3个重点练习词及复习词。重点词在生成后审核时选定，复习词在生成前选定；继承家长已采用的支持建议，允许成人调整。

验收：三档难度分别实施8／12／16词上限；复习词实际出现在故事中；开课后设置不改变本课材料；用时、错误和休息不会自动改变难度。

**PRD-006 儿童首页。** 中部只有“我的故事”和1个预置示例，显示本课活动步骤。故事卡片以边框、图标及“已选择”同时表示状态。

验收：未选择时开始按钮禁用；选择我的故事进入成人录入；选择示例进入成人确认；示例加载失败有重试、帮助、休息及结束入口。

### 6.2 输入 生成与审核

**PRD-007 中文文字输入。** 提供20–150字建议、实时字数、300字硬性上限和完整预览。空白输入禁止提交，信息不足时要求补充。

验收：300字可进入确认，301字被阻止；空白输入不调用生成；系统不替儿童补写真实经历；文字修改后须重新确认发送。

**PRD-008 成人语音录入。** 获得产品授权后，成人点击开始才请求浏览器麦克风权限，提供开始、停止、取消、上传、转写与编辑状态。跟读默认不录音。

验收：60秒或3 MB达到任一限制即停止；成人确认转写后才可生成；权限拒绝、设备不可用和格式不支持均解释原因，文字入口始终可用；停止、取消或离开录音页后释放麦克风。

**PRD-009 发送确认和身份信息提醒。** 提交前显示处理说明，提醒删除真实姓名、详细地址、联系方式和学校，提供返回修改与改用虚构情节的入口。

验收：未确认全文不能提交；检测到明显联系方式时要求修改；日志、错误提示和公共页面不包含私人输入。

**PRD-010 生成任务。** 显示真实阶段、取消入口和失败原因，支持在相同已确认输入上重试，自动重试最多3次。

验收：1秒内出现处理状态；同一次重复请求只建立1个任务；45秒文字期限包含所有尝试和等待；取消后返回的内容不进入审核或儿童页面；成人主动选择示例时清楚标注。

**PRD-011 内容结构与安全。** 产出第4.1节规定的句子、词卡、三类题目及图片。系统校验数量、词数、引用、答案唯一性和媒体完整性；文字和图片均通过安全检测。

验收：任一校验失败时不能批准；未检测、检测失败、服务不可用或部分生成的材料不得进入儿童端；不合格部分仅在限定次数与期限内重新生成；返回相应失败原因。

**PRD-012 成人审核与内容版本。** 审核页展示全部英中词句、词卡、题目、答案、图片、重点词和检查项。修改词句、难度、题目或图片产生新版本，并重新校验审核。

验收：批准记录包含成人、时间和内容版本；旧题目、旧音频与旧绘本不能混入新版本；儿童正在使用的审核版本在本课中保持固定；成人修改用于另一次课程，不替换进行中的课。

**PRD-013 预置示例。** 示例材料包含真实可用的句子、5张词卡、三类题目、图片和音频，预先审核，界面持续标注“示例故事”。成人确认后使用。

验收：不调用实时生成也可完成示例课；公开示例文件不包含答案；示例来源和 AI 标识按素材实际情况填写；个人记录仅在相应授权和档案存在时写入。

### 6.3 儿童学习

**PRD-014 逐句听读。** 每屏一句，英中图相邻排列，提供播放、停止、上一句和下一句。声音、按钮和当前句一致。

验收：首次进入、休息返回、切换句子和返回前台均不自动播放；多段声音不叠加；首句禁用上一句，末句进入练习；音频失败保留当前句并允许重试。

**PRD-015 词卡。** 一次展开一张，展示图片、英文、语境中文和来自故事的例句；可查看全部5张并返回原句。

验收：例句包含当前词；图片与释义匹配；关闭词卡和休息返回后原句及词卡索引正确；只浏览词卡不会被判定为独立完成。

**PRD-016 看中文选英文。** 一道题提供3个英文选项，正确答案唯一。确认前可更换，未选择时确认禁用并说明原因。

验收：服务端判定正确性；页面加载和题目响应不包含答案字段；答错可重试或跳过；不自动进入下一题。

**PRD-017 单词配对。** 每题2–3组，依次选择英文和中文，通过点击逐组确认，允许撤销未提交选择。

验收：选定两侧后才能确认；配错不清除已完成组；所有配对完成后主按钮变为进入下一题；跳过保留已经完成的组；休息后恢复已完成组和未提交选择。

**PRD-018 词库填空。** 对故事句中的1个空格，从2–3个候选词中选择后确认，无需键盘输入和拖动。

验收：只有1个候选项满足目标词与句意；题目存在歧义时禁止审核通过；修改候选答案不会提前提交。

**PRD-019 作答 反馈与重做。** 确认后分别记录首次、提示后和重做结果，以及是否得到成人帮助。错误反馈温和、具体，提供重听、提示、重试和跳过。

验收：网络重发同一提交只记1次；儿童主动重做生成新次序的记录；跳过记为未完成；反馈持续显示至主动继续；反馈和题目不使用红叉、警报、生命值与排名。

**PRD-020 帮助。** 所有儿童页面提供固定帮助入口，分步指令持续可见，可重听指令、查看提示和请成人协助。

验收：打开帮助不清空选择；提示和成人协助被记录为支持条件；显示帮助不会移动当前选择控件；纯点击和键盘均可完成。

**PRD-021 休息与结束。** 所有儿童页面可休息或结束。休息保留当前句、题、选择、配对进度、反馈阶段和词卡；继续时回顾当前任务。

验收：休息立即停音频与动效；返回不重复提交、不自动播放；结束保存已提交记录并标明未完成项目；刷新或会话失效时解释范围，不展示虚构恢复结果。

### 6.4 作品 记录与建议

**PRD-022 绘本生成与下载。** 成人确认后生成1张1080像素宽的 PNG，含本课全部英语句子、配图、标题和适用的 AI 生成标识。

验收：材料来自相同审核版本；文字全部保留且能够阅读；图片或字体加载失败时保留预览、返回真实失败原因；应用只在浏览器已发起下载后提示“已交给浏览器下载”，不宣称设备文件已保存。

**PRD-023 本课结果。** 展示已听读句子、已查看词卡、已完成和跳过的练习，区分自然结束与提前结束。家庭可进入家长记录，机构可进入小组摘要。

验收：本课统计可追溯到真实事件和提交；没有发生的环节保持未完成；机构集体或归属不明的作答不会写入儿童个人记录。

**PRD-024 词语学习证据。** 按词语和按课程查看“初次接触”“提示下完成”“独立完成”“延迟复习中独立完成”。展示最近结果及历史日期、题目、提示条件和成人协助情况。

验收：尚未接触显示“尚未练习”；答错、跳过和仅听读不会产生独立完成；同题答错后再答对保留重做条件；单次答对不显示“已掌握”；历史证据不被最新结果覆盖。

**PRD-025 延迟复习。** 成人可在下次课程选入已学词，系统在新故事和新题中安排复习，判定采用第4.1节的24小时间隔。

验收：同一课反复作答或24小时以内复习不标记为延迟复习；成人帮助或提示后完成不计为延迟独立完成；复习证据关联前次独立完成记录。

**PRD-026 一条陪伴建议。** 从人工维护的建议库选择与本课实际使用支持相关的1条建议，显示对应理由；家长可采用、取消采用、调整并标记是否有帮助。

验收：采用后进入同一儿童下次设置；其他档案不继承；重复点击不会重复保存；没有足够证据时显示一条一般陪伴建议并说明适用条件；用时和休息次数不折算为英语成绩。

### 6.5 共享与数据管理

**PRD-027 指定对象共享。** 家长再次验证身份，选择具体作品或记录范围、接收人手机号和有效期；默认7天，可设置1–30天，接收人通过该手机号验证码访问。

验收：未授权分享不能创建；链接单独转发无法绕过接收人验证；接收人只能读取所选对象；撤销后新请求立即拒绝；界面说明已经下载的文件由接收人保管。

**PRD-028 数据导出。** 家长再次验证身份后选择儿童档案，查看导出范围和任务进度，下载包含 JSON 数据、可读 CSV 记录、PNG 作品及字段说明的 ZIP。

验收：包含授权、档案、课程、版本、作答、词语证据和作品关联；不包含其他家庭、明文凭据和已清理录音；失败返回原因；下载地址有效期30分钟，导出产物24小时后删除。

**PRD-029 删除与注销。** 分别提供删除单个档案和注销成人账号，列明受影响课程、记录、作品、共享与导出任务，验证身份并确认后执行。

验收：确认后立即关闭访问并撤销共享；数据库、对象文件和缓存按任务清单删除；界面仅在所有在线数据处理完成后显示“已完成”；备份残留及到期时间明确说明，恢复备份时重新应用删除清单。

**PRD-030 机构摘要与清理。** 摘要只含当课匿名小组的参与情况、完成环节、练习结果与使用支持，不含个人长期画像。提供作品预览和下载后，成人结束课堂。

验收：结束后旧凭证立即失效，临时故事、媒体、作答和摘要进入清理；15分钟内清理全部在线内容，失败状态可查且持续告警；异常关闭按租约回收；提示处理共享设备已下载的图片。

### 6.6 项目展示与统一体验

**PRD-031 公共项目页面。** 提供产品介绍、使用指南、常见问题、隐私说明、联系方式和进入应用入口。指南覆盖成人准备、审核、听读练习、休息和查看记录。

验收：手机与电脑可访问全部页面；链接、标题、图片说明可由读屏识别；所有案例明确为示例；不展示儿童个人信息；无正式联系方式时不得填充虚构联系人。

**PRD-032 产品海报。** 交付电子版 Poster 及设计源文件，采用实际产品页面和清楚标识的示例，二维码链接稳定的公共介绍地址。

验收：二维码可打开当前项目页面并进入应用；文案与实际交付功能一致；附字体和图片授权清单。

**PRD-033 成人与儿童权限切换。** 交给儿童后锁定成人页面；进入审核、设置、记录、共享、导出和删除均按角色验证。查看家长记录及每次敏感写操作需要新一次成人验证。

验收：仅隐藏按钮无法替代接口权限；儿童会话不能通过直接请求读取答案或家长数据；机构口令不能用于家庭数据；退出、撤回授权和删除后旧访问能力立即失效。

**PRD-034 无障碍与低干扰交互。** 采用第7章全部规则，覆盖首页、听读、练习、帮助、休息、本课完成和作品预览。

验收：所有儿童页面逐项通过字体、对比度、操作尺寸、纯点击、键盘、读屏、缩放和减少动效检查，任一主流程无法操作均阻止正式交付。

## 7 页面与交互要求

### 7.1 布局与文字

儿童页顶部显示页面名称、当前句或题的进度，右上方为成人入口；中部只显示当前任务；底部左侧固定帮助和休息，右侧为唯一实色推进按钮。结束入口在休息页和帮助面板内始终可达。播放、上一句等次要按钮使用描边样式。

手机底部采用两行操作区，内容区预留实际按钮高度和系统安全区域。平板和电脑可将同一任务图文分栏，任务数量保持不变。浏览器缩放至200%时可纵向滚动，正文、提示、退出和按钮均可访问。

| 项目 | 要求 |
| --- | --- |
| 儿童正文 | 20–24 CSS px，行高约1.5倍 |
| 重点英语 | 24–32 CSS px |
| 成人正文 | 至少16 CSS px |
| 主要操作目标 | 至少56×56 CSS px，相邻操作间距至少12 CSS px |
| 正文对比度 | 至少4.5:1 |
| 大文字 控件与焦点 | 至少3:1；状态同时提供文字或图标 |
| 背景与正文 | 暖白 #FFF9F0；深蓝灰 #243248 |
| 主操作与支持区域 | 蓝色 #2F64D6，白色按钮文字；浅薄荷 #DDF3EA配深色文字 |

### 7.2 声音 焦点与反馈

默认关闭背景音乐、振动和装饰动效，提供静音和音量控制，跟随浏览器减少动效偏好。声音承载的重要信息同步显示文字。禁止自动播放、自动跳句、自动跳题、闪烁、自动轮播、滚动字幕、背景视频和重复弹出提醒。

按钮与图标提供完整可访问名称，使用正确的选中、禁用、展开和进度状态。任务切换后焦点进入任务标题；关闭面板后回到原触发按钮；反馈以温和的读屏提示通知。配对通过选择两侧卡片完成，所有操作可使用键盘，无需拖动。

## 9 非功能要求与质量目标

| 编号 | 领域 | 验收目标 |
| --- | --- | --- |
| NFR-01 | 浏览器 | 交付时 Chrome、Edge、Firefox 当前及前一稳定主版本，macOS Safari 当前及前一主版本；真实 iPhone／iPad Safari、Android Chrome覆盖完整主流程，记录实际系统与版本 |
| NFR-02 | 响应式 | 360–1920 CSS px宽度可用；200%缩放可操作；软键盘打开和横竖屏切换不遮挡按钮 |
| NFR-03 | 界面反馈 | 本地选择和按钮状态200毫秒内反馈，异步操作1秒内显示处理状态；阈值按测试记录的95百分位评估 |

| NFR-05 | 生成 | 文字目标45秒内完成，包含最多3次自动重试；图片和音频使用独立期限，等待页显示真实阶段，无法完成时明确失败 |

| 数据导出产物 | 生成后24小时删除，下载凭证有效30分钟 | 下载或重新发起 |
| 在线数据删除 | 接受任务后立即关闭访问，24小时内完成；超时或失败显示实际状态 | 查看进度、重新验证后重试 |
| 系统日志 | 去除私人内容，保留30天 | 由授权维护人员排查服务问题 |
| 备份 | 加密保存，最长30天；已删除内容不得在恢复后重新开放 | 隐私页面说明最长残留期限 |

时间参数属于本文确定的实施要求。服务供应商的数据处理范围和保存方式须在启用对应服务前核实并写入隐私说明；供应商未满足要求时，该服务不得启用。
